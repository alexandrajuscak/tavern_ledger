## Source conflicts

- **Artificer multiclass spell slot rounding**: Black Citadel says half the levels, rounded down; decision: half_up (Tasha's Cauldron of Everything, Artificer multiclassing). Evidence: the Artificer single-class table equals the standard table at ceil(level / 2) at every level; dnd5e.wikidot.com has no multiclassing page (404).
